# Task: Brain Compaction  (schedule: weekly, e.g. Sunday night)

Act as the orchestrator with the `brain` skill. Compile the week's raw notes into the wiki.

1. Read all brain/raw/ entries created since the last compaction (check the "Last compaction"
   line in brain/wiki/index.md).
2. For each SKU touched, update brain/wiki/skus/<SKU>.md: latest velocity/margin/lead-time,
   new known issues, what worked or didn't, links to the source raw notes.
3. Promote any pattern seen 2+ times into a brain/wiki/playbooks/<topic>.md note.
4. Update customers.md and competitors.md with new themes.
5. Update brain/wiki/index.md: open questions/hypotheses + a one-line "Last compaction" summary
   with today's date.
6. Deduplicate; keep wiki tight. Never modify or delete raw/.

Report a 5-line summary of what changed in the wiki this week.
