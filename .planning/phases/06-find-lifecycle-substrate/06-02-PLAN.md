<objective>
Implement the hand-written lifecycle classifiers that turn an `actions_start dryRun:true`
response (WRITE-01) and an `actions_get` poll response (WRITE-05) into typed proceed/stop/refuse
verdicts, plus the two thin CLIs that wrap each op in `logged_call`. This makes the RED tests
from Plan 01 GREEN. No `dryRun:false` ever fires; the classifiers operate on agent-handed JSON.

Purpose: WRITE-01 and WRITE-05 — the dryRun validation gate and the poll-to-terminal
reconciliation discipline. The verified enum (pinned in Plan 01) is consumed here so a real
`ERROR`/`CANCELED` is terminal (no infinite spin) and an unmodeled status refuses rather than
being assumed terminal or polled forever.

Output: `lifecycle.py` (the load-bearing classifier core) + `classify_dryrun.py` /
`classify_poll.py` (thin CLIs mirroring `answer_tacos.py`).
</objective>
