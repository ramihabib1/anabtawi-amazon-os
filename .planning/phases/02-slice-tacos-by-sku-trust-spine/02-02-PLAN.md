<objective>
Build the hand-written, pytest-covered money-logic core (`tacos.py`) and the thin CLI
(`scripts/answer_tacos.py`) that together turn a downloaded premium-export artifact into
the typed "TACOS by SKU" answer: ratios read (never recomputed) from the source columns,
the TACOS<=ACOS sanity guard, the no-data sentinels, the threshold-breach flags, and the
empty/failed refusal. Ship the synthetic-scaffold fixture and the unit tests that prove
each edge against it.

Purpose: This is the only hand-written money-touching code in the phase (CLAUDE.md hard
rule 4). Ratios stay source-computed (D-03); Python only compares (sanity guard, breach
flag) and classifies (no-data, refusal). The CLI is the seam the Hermes skill (Plan 03)
calls after the agent downloads the artifact via the DataDoe MCP.

Output: src/habibos/tacos.py, scripts/answer_tacos.py, a synthetic fixture, an explicit
committed CA catalog list, and a green tests/test_tacos.py. The fixture and catalog list
are temporary scaffolds — Plan 03 re-points the fixture and re-seeds the catalog from the
real captured export.
</objective>
