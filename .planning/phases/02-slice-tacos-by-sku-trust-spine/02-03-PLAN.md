<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Hermes agent -> DataDoe MCP | Read-only Amazon data crosses in; agent invokes the MCP (no Python HTTP client) |
| live export artifact -> committed test fixture | A real export becomes a tracked file; must not embed secrets/PII |
| skill rendering -> operator | A fabricated number on no-data is the core project risk; refusal must surface verbatim |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-11 | Tampering | Python recomputing the window ratio because the source can't groupBy server-side (A1) | mitigate | SKILL.md instructs groupBy seller_sku so the source computes the ratio; the live-pull checkpoint confirms A1 and ESCALATES to the operator rather than recomputing (D-03) |
| T-02-12 | Tampering | percentage-unit mismatch making the breach flag 100x off (A2) | mitigate | live-pull checkpoint confirms the convention against the artifact and records it; re-pointed fixture pins it; test_ratio_units re-asserts |
| T-02-13 | Information Disclosure | seller UUID or PII committed into the real fixture or inlined in SKILL.md | mitigate | SKILL.md references $AMAZON_CA_SELLER_ID (grep gate forbids the literal); fixture capture sanitizes sensitive columns; test_env.py scans tests/ for the literal |
| T-02-14 | Repudiation/Spoofing | skill claiming an Amazon action or substituting a number on a Refusal | mitigate | SOUL.md recommendation voice; skill surfaces Refusal reason verbatim; TRUST-04 checkpoint verifies no-data/refusal cells are correct |
| T-02-15 | Tampering | marketplace bleed (US SKUs in a CA answer) | mitigate | filters marketplace CA (A2EUQ1WTGCTBG2); TRUST-04 checkpoint confirms CA-only scope |
</threat_model>
